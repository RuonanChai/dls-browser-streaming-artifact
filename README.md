# DLS Browser Streaming — Experiment Artifact (Anonymous)

Experiment harness to reproduce the **Demand Lookahead Scheduling (DLS)** evaluation on **Spark 2.0** + **Playwright** + **CDP** instrumentation.

This repository contains **measurement code only** (no paper figure plotting scripts).

## What is included

```
overlay/
  src/                          # DLS patch (SplatPager + SparkRenderer fetch path)
  scripts/ready_single_user/    # Trial runner, matrix, analysis, audits
  scripts/proactive_single_user_v2/  # CDP enrichment helpers
  scripts/lib/                  # Browser ablation cell, proactive/READY controllers
  vrc-paper/experiments/        # CDP network audit I/O
  config/experiment_matrix.json # Phase/batch definitions (URLs sanitized)
docs/                           # Batch list + baseline parameters
install_overlay.sh              # Copy overlay onto Spark checkout
```

**Not included:** LaTeX sources, `plot_*.py` figure scripts, screenshot composers, raw `paper_materials/` trial outputs (re-generated by running experiments).

## Prerequisites

- **Node.js** ≥ 18, **npm**
- **Spark 2.0** source tree ([sparkjs.dev](https://sparkjs.dev/) public repo) with `npm run build` working
- **Playwright Chromium** (installed via Spark's `npm install`)
- **NVIDIA GPU + Chrome** recommended (harness uses RTX-class laptop settings; CPU-only not validated)
- Access to:
  - a **local / LAN edge** `.rad` URL (optional, for §2 three-path table)
  - a **remote object storage / CDN** URL serving the same Coit Tower 40M LOD asset

## Quick start

### 1. Clone Spark and this artifact

```bash
git clone https://github.com/sparkjs-dev/spark.git spark-dls-eval
git clone <THIS_ANONYMOUS_REPO_URL> dls-artifact
```

### 2. Install overlay

```bash
bash dls-artifact/install_overlay.sh spark-dls-eval
cd spark-dls-eval
npm install
npm run build
```

### 3. Configure delivery URLs

Set environment variables (or edit `config/ready_single_user/experiment_matrix.json`):

```bash
export EDGE_SERVER_HOST="10.x.x.x"          # LAN edge host
export REMOTE_COS_URL="https://bucket.example.com/path/to/coit-40m-sh1-lod.rad"
# Optional alternates used in matrix: REMOTE_CDN_URL, REMOTE_GCS_URL
export VRC_RAD_MANIFEST_CSV="path/to/rad_manifest.csv"   # byte ranges per chunk
```

The runner resolves `.rad` asset URLs from `experiment_matrix.json` → `deliveries.*.asset_url`.

### 4. Run a batch

From Spark repo root:

```bash
# Example: main DLS result (burst_turn, n=5)
node scripts/ready_single_user/run.mjs --phase=dls-main-burst-cos-n5 --trials=5

# Example: failed optimizations (orbit, n=5)
node scripts/ready_single_user/run.mjs --phase=failed-approaches-cos-n5 --trials=5

# Filter methods
node scripts/ready_single_user/run.mjs --phase=dls-main-burst-cos-n5 --trials=5 --methods=spark_od,dls
```

Outputs default to `paper_materials/ready_single_user_v1/runs/<phase>/`.

### 5. Aggregate metrics (tables, not figures)

```bash
node scripts/ready_single_user/analyze.mjs --batchDir=paper_materials/ready_single_user_v1/runs/dls-main-burst-cos-n5
node scripts/ready_single_user/extract_metrics.mjs
node scripts/ready_single_user/baseline_config_audit.mjs
```

## DLS implementation surface

Modified hot path: `src/SplatPager.ts` → `driveFetchers()`.

Runtime knob:

```javascript
window.__sparkSdlK = 4;  // lookahead depth K; 0 = Spark-OD
```

Gate condition (strict): enqueue lookahead only when **no pending demand** and **zero in-flight fetchers**, append at queue tail; visible chunks are rebuilt at queue head each frame in `SparkRenderer.ts`.

## Reproducing paper numbers

1. Match batch ID and `n` from `docs/BATCHES.md`.
2. Compare **within-batch** Spark-OD vs DLS deltas (absolute Q5 varies across days/sessions).
3. Gap decomposition and demand timeline are derived offline from `cdp_network_audit.csv` + chunk state in trial JSON (scripts for those derivations live in the separate writing repo; not part of this artifact).

## Troubleshooting

| Issue | Check |
|-------|--------|
| `__slDiagCam` null | Wait for Spark init in ablation HTML probe |
| Zero `.rad` requests | `VRC_RAD_MANIFEST_CSV`, asset URL reachability |
| CDP audit empty | Playwright trace enabled; `--no-proxy-server` flags in trial cell |
| Port conflicts | `node scripts/ready_single_user/port_cleanup.mjs` |
